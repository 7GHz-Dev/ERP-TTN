# TTN แพลนลากตู้

เว็บแอปจัดการแพลนลากตู้คอนเทนเนอร์: รับแพลนจาก partner → จัดคนขับรถบริษัทก่อน → ถ้าไม่พอหารถร่วม → ติดตามสถานะจนคืนตู้ → สรุปค่าใช้จ่าย/ข้อความส่ง LINE

- **Next.js 16** (App Router) บน **Vercel**
- **Supabase** (Postgres + Auth + Realtime) เป็นฐานข้อมูล — ข้อมูลเดิมย้ายมาจาก Google Sheet ด้วยสคริปต์ `import-sheet`

## หน้าจัดการแพลนลากตู้ (เฟส 1)

| ทำอะไรได้ | รายละเอียด |
|---|---|
| นำเข้าแพลน | วางข้อความจาก Excel/LINE ระบบหาเลขตู้ BL น้ำหนัก ท่าให้เอง, ตรวจ check digit เลขตู้ (ISO 6346), เตือนตู้ซ้ำ/ตู้ที่ยังมีงานค้าง |
| จัดรถอัตโนมัติ | รถบริษัทก่อน → รถร่วม, ในกลุ่มเดียวกันใครว่างนานสุดได้ก่อน, ข้ามคนที่มีงาน/กำลังวิ่ง/แจ้งไม่ว่าง, ตู้หนัก (≥ 20 ตัน) ให้คนที่รับงานหนักได้, ไม่ใช้กะบะตู้ทึบ |
| จัดรถเอง | คลิกแถวตู้ → คลิกคนขับในแผงขวา (ระบบเลื่อนไปตู้ถัดไปให้) หรือกด "เลือกคนขับ" ในแถว |
| ราคาค่าเที่ยว | แนะนำจากตาราง `rates` ตามปลายทาง + ประเภทรถ (+ น้ำหนัก), แก้เองได้ในแถว |
| สถานะ | รอจัดรถ → จัดรถแล้ว → กำลังวิ่ง (รับตู้) → ปิดงาน (จบงาน) → คืนตู้ — กดปุ่มเดียว มี "เลิกทำ" |
| แจ้งเตือนคืนตู้ | ตู้เกินกำหนด / ครบกำหนดภายในพรุ่งนี้ |
| ข้อความ LINE | จ่ายงาน (พขร.), แจ้งงานแม่สอด, สรุปคนรับงาน (ชิปปิ้ง), ตั้งเบิก (บัญชี), หารถร่วม |
| คนขับ | สถานะว่าง/มีงาน/กำลังวิ่ง/ไม่ว่าง ต่อวัน, เพิ่มคนขับรถร่วม, แจ้งวันไม่ว่าง (ลา/ซ่อมรถ/งานนอก) |
| หลายคนใช้พร้อมกัน | Realtime: เปิดหลายเครื่องเห็นการเปลี่ยนแปลงทันที |

## ติดตั้งครั้งแรก

### 1. Supabase

1. เปิด SQL Editor แล้วรันไฟล์ [`supabase/migrations/20261118000000_init.sql`](supabase/migrations/20261118000000_init.sql)
2. **Authentication → Sign In / Providers → ปิด "Allow new users to sign up"** (ให้เฉพาะคนที่แอดมินสร้างบัญชีให้เท่านั้นเข้าได้)
3. **Authentication → Users → Add user** สร้างบัญชีให้ทีมจัดรถ (อีเมล + รหัสผ่าน)

ทุกตารางเปิด Row Level Security: ต้องล็อกอินจึงอ่าน/เขียนได้

### 2. ตั้งค่าเครื่อง

```bash
cp .env.example .env.local   # ใส่ publishable key, secret key, GOOGLE_SHEET_ID
npm install
```

### 3. ย้ายข้อมูลจาก Google Sheet

```bash
npm run import-sheet -- --dry-run   # ดูสรุปก่อน ไม่เขียนฐานข้อมูล
npm run import-sheet                # นำเข้า (รันซ้ำได้ — เพิ่มเฉพาะแถวใหม่ ไม่ทับที่แก้ในแอป)
```

อ่านจากชีต `DriverMaster`, `Queue` (ประเภทที่รับงาน), `WorkLog`, `งานนอก` และตั้งอัตราค่าขนส่งเริ่มต้นจาก "ราคาที่จ่ายบ่อยที่สุด" ต่อปลายทาง + ประเภทรถ
ข้อมูลคนขับ/บัญชีธนาคาร **ไม่ถูกเก็บใน git** — สคริปต์อ่านจาก Sheet ตอนรันเท่านั้น

ไฟล์ Excel ชีตเดียวแบบ WorkLog (ไม่มี DriverMaster) เช่น `file/จัดการคนรถ 2026.xlsx` ใช้อีกสคริปต์:

```bash
npm run import-worklog -- --file "file/จัดการคนรถ 2026.xlsx" --dry-run   # ดูว่าจะเพิ่ม/อัปเดตอะไร
npm run import-worklog -- --file "file/จัดการคนรถ 2026.xlsx"             # เขียนจริง (รันซ้ำได้)
```

จับคู่ตู้เดิมด้วยเลขตู้ + วันรับตู้ / BL แล้วอัปเดตแทนการเพิ่มซ้ำ, คนขับที่ไม่มีในระบบถูกสร้างแบบปิดใช้งาน
โฟลเดอร์ `file/` ไม่ถูกเก็บใน git

อัปเดตรายชื่อคนรถจาก `file/driver master.xlsx` (ชื่อ ทะเบียน โทร บัญชี):

```bash
npm run import-drivers -- --file "file/driver master.xlsx" --dry-run
npm run import-drivers -- --file "file/driver master.xlsx"
```

คนในไฟล์ถูกอัปเดต + เปิดใช้งาน, ถ้าไฟล์มีรถบริษัท ถือเป็นรายชื่อรถบริษัทครบชุด — รถบริษัทที่ไม่อยู่ในไฟล์ถูกปิดใช้งาน

### 4. Vercel

ตั้ง Environment Variables 2 ตัว: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
(ห้ามใส่ `SUPABASE_SECRET_KEY` ใน Vercel)

## พัฒนา

```bash
npm run dev     # ต่อ Supabase ตาม .env.local
npm run demo    # โหมดสาธิต: ข้อมูลสมมติในเบราว์เซอร์ ไม่ต้องมี Supabase / ไม่ต้องล็อกอิน
npm test        # unit test ของ logic (จัดรถ ความว่าง ราคา แปลงข้อความ ข้อความ LINE)
npm run lint
```

โครงสร้าง

```
src/lib/logic/     กฎธุรกิจล้วน (มี test): assign, availability, pricing, parse-plan, messages, status, container
src/lib/data.ts    อ่าน/เขียน Supabase
src/components/board/  หน้าจัดการแพลน
supabase/migrations/   schema
scripts/import-sheet.ts
```

## ค่าที่ตั้งไว้ (ปรับได้)

- ตู้หนัก = น้ำหนัก ≥ **20 ตัน** (`DEFAULT_HEAVY_TONS` ใน `src/lib/logic/assign.ts`)
- WH Tax = 1% ของ (ค่าเที่ยว + น้ำหนักเกิน + ค้างคืน) เฉพาะรถร่วม, รถบริษัท = 0 — ตามสูตรเดิมใน WorkLog
- วันไม่ว่างนับรวมวันเริ่มและวันสิ้นสุด, ไม่ใส่วันสิ้นสุด = ไม่มีกำหนด
- คนขับที่มีตู้ในวันแพลนเดียวกันแล้ว หรือรับตู้แล้วยังไม่จบงาน = ไม่ว่าง (เลือกเองได้แต่ระบบจะเตือน)
